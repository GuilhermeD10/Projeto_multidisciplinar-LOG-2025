# Projeto_multidisciplinar-LOG-2025
Projeto desenvolvido em 2025, durante o 3º ano do Ensino Médio integrado ao itinerário formativo profissionalizante técnico em Logística. O trabalho analisa o transporte e os riscos associados ao armazenamento de materiais bélicos, utilizando dados públicos, gestão de riscos e soluções tecnológicas para ampliar a segurança logística.
